# v1.4.0 Release Notes

Release date: 2026-10-18.

Published on [GitHub](https://github.com/aiden0z/pptx-renderer/releases/tag/v1.4.0) and
[npm](https://www.npmjs.com/package/@aiden0z/pptx-renderer/v/1.4.0).

## Summary

v1.4.0 adds host control over external media requests and exposes layout/master shapes in
serialized presentations. It also fixes hidden-object visibility, preset-shape text placement,
background-filled shapes, chart labels and axes, and wrapped text autofit.

## Added

- `externalMedia: 'allow' | 'block'` on `PptxViewer`, the compatibility renderer, thumbnails,
  and standalone `renderSlide()`. The default remains `allow`; use `block` to prevent loading
  external picture, shape/background/text-fill, audio/video and poster relationships (#32).
- `serializePresentation()` includes typed layout/master template shapes and each slide's
  `layoutPath`, `masterPath` and `showMasterSp` references (#30). Authored visibility metadata
  is retained even when a node is not rendered (#36).

## Fixed

- Respect `cNvPr@hidden` on slides, layouts, masters, OLE previews and nested groups; hidden
  content does not start media loading (#36).
- Position preset-shape text in the standard DrawingML text rectangle while preserving explicit
  text transforms, adjusted geometry, group coordinates and degenerate-guide fallbacks (#37).
- Sample `useBgFill` backgrounds in slide coordinates before clipping to shape geometry,
  including 2D rotations/flips/groups, inherited backgrounds, lazy images and the default white
  background. Template shapes sample their own master/layout background chain; explicit local
  fills keep priority (#34, contribution by @Arcadi4).
- Honor chart label number formats and point-level source-linked resets; reserve bottom legend
  space and improve automatic positive-axis bounds (#33).
- Measure wrapped line height for autofit; preserve existing CJK wrapping/spacing behavior (#35).
- Improve text tabs, terminal hanging punctuation, vertical text, picture-filled runs and
  placeholder style inheritance (#25, #27, #29).

## Migration Notes

No API migration is required. New options and serialized fields are additive. Applications
that want external-media blocking must opt in:

```ts
const viewer = new PptxViewer(container, { externalMedia: 'block' });
```

This policy controls external media relationships. It does not prevent loading a presentation
URL chosen by the host, user-activated navigation, host-configured fonts, or an optional PDF.js
runtime. It is not a general network sandbox. Embedded package media remains available.

## Validation and Support Boundaries

Release checks cover unit tests, browser behavior, package entries, geometry generation,
PDF.js compatibility and bundle budgets. Targeted native PowerPoint references cover the reported
text, visibility, chart and background-fill defects. They do not establish whole-corpus fidelity.

The original #37 attachment's text positioning is corrected. A matching Calibri font profile
passes the native comparison gate; system-font fallback changes text metrics. Theme-inherited
text shadows and gradient interpolation retain pre-existing visual differences. Existing support limits for general 3D, effect combinations, OMML,
SmartArt and vector fallbacks still apply. The new background-fill coordinate handling covers
2D shape/group transforms; arbitrary 3D projection and effect combinations are not newly claimed.

## Release Verification

The final candidate passed 3514 unit tests, 137 browser tests, and 48 fixture-generator tests,
plus type/lint/format, geometry, package, bundle-size, and PDF.js 5/6 checks. The merged source tree
matches the tested candidate, and the npm tarball matches the GitHub Release attachment.

Issue #37 was retested with its original PPTX attachment; #32 used the issue's exact public
generator. Issue #36 did not provide its private original file, so verification used a derived
reproduction and browser controls. Background-fill verification used retained #34 reproductions
and fresh native PowerPoint probes for master/layout background ownership. Existing global
gradient differences remained below the full-slide visual gate on four reproduction pages;
thresholds and baselines were not relaxed. These results do not imply that every native visual
comparison passes.
